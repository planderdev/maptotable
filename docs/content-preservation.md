## 표현 변경

검은 알약 헤더와 주민별 원색 목록을 교체했습니다. 후속 요청에 따라 히어로는 풀블리드 100svh 사진과 오버레이 헤더로 변경했고, 반복된 화살표·카드 배지·프로그램 장식 아이콘을 제거했습니다. 중립색 `--neutral-900: #121212`, 타이틀·진행 막대만 남긴 히어로, 모바일 `MAP / TO / TABLE` 세 줄과 헤더 프라이머리 버튼, 히어로 핀과 소개 제목의 마스크·투명도 모션, 큰 브랜드 타이포그래피, 비대칭 편집형 목록, 16/24px 모서리 체계와 단계별 폼을 적용했습니다. 새 아이브로우, 슬로건, 주민 인용문, 일정·가격·주소·문의처는 추가하지 않았습니다.

음식 이야기 목록은 KANU의 상승 카드 구간을 참고해 중앙 제목과 우·좌·우 사진 흐름으로 변경했습니다. 공개 이야기 1·2·3의 순서와 링크·사진 소유 관계는 유지합니다. 후속 요청으로 흰 배경과 음식 / 삶 / 기억 세 줄 제목을 적용하고, 보조 설명과 4·5·6 준비 상태 카드의 렌더링은 제거했습니다. 새로운 원고·이름·음식 정보는 추가하지 않았습니다.

생성 정물과 Pixabay 영상은 전시 소개의 보조 에셋입니다. 사용자의 후속 요청으로 화면의 이미지·영상 설명과 출처 표시는 제거했습니다. 이미지 대체 텍스트, 영상 장면 설명 트랙과 내부 출처 문서는 보존합니다. 주민의 실제 식사, 프로그램 현장이나 제주 촬영물로 주장하지 않습니다. 레퍼런스의 카피·사진·영상·로고·그래픽은 사용하지 않았습니다.

프로그램 레일은 KANU의 세로 사진 카드 레퍼런스를 따라 풀브리드로 확장했습니다. 이름·설명·대상·일정 미정 안내는 그대로 두고 장식 아이콘 대신 생성 사진, 순번과 텍스트 오버레이를 사용합니다. 사진은 실제 현장으로 주장하지 않으며 원본·프롬프트는 작업 폴더 안에 보존합니다. 화면의 출처·설명 캡션은 추가하지 않았습니다.

소개의 사진·확대 모션과 좌우 레이아웃은 제거했습니다. 제목은 텍스트 마스크와 opacity로, 소개 원문은 기존의 세 문장으로 각각 보여 주며 하단에 기존 주민 사진 마퀴를 연결합니다. 영상의 화면 버튼은 제거하고 무음 자동재생과 클릭·키보드 전환을 유지합니다.
